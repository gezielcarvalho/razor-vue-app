# Project charter

## Purpose

Demonstrate progressive integration of Vue 3 components into an ASP.NET Core Razor Pages application, with development hot reload and production static bundles.

## Verified scope

- .NET 8 Razor Pages shell and static-file serving.
- Vue 3 sample component mounted from a Razor page.
- Webpack/Vue loader build pipeline and Webpack Dev Server.
- Environment-aware development versus static-bundle loading.

## Portfolio decision

This is a hybrid-rendering reference starter, not a product. Keep it as an archive/reference candidate; use `dotnet-vue` for the primary .NET/Vue showcase.
